This crate contains literal protocol fixtures and small helpers used only by tests. It has no dependency on Radia's production crates. The `llsd`, `network`, `protocol`, `world`, and `viewer` packages use it only as a dev-dependency. Fixture bytes must not be generated by Radia's encoder or decoder.

`fixtures/lludp/` holds hand-built protocol vectors. Optional sanitized wire samples should live under `fixtures/lludp/captured/` with their provenance. Real `.capture` archives stay in the user's local application-data folder and are never committed. Run `cargo xtest -p viewer --run-ignored only capture` to validate completed local archives on demand.

`allocation` supplies a system allocator and synchronous measurements for the calling thread. Each consuming test binary installs the allocator itself. Use it to verify decoded-memory admission and release; it does not measure process RSS or work on other threads. Network's process-wide probes remain local to Network because their measurement scope differs.
