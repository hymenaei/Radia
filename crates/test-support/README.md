# Test support

This crate contains literal protocol fixtures and small helpers used only by tests. It has no dependency on Radia's protocol or network crates. The `network`, `protocol`, and `viewer` packages use it only as a dev-dependency. Fixture bytes must not be generated by Radia's encoder or decoder.

`fixtures/lludp/` holds readable, specification-derived packet vectors. Real `.capture` archives stay in the user's local application-data folder and are never committed. Run `cargo xtest -p viewer --run-ignored only capture` to validate completed local archives on demand.
